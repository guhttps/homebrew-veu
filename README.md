# Homebrew tap do Véu

Esconde dados pessoais e segredos antes de o texto chegar à IA e devolve os dados reais na resposta.

```bash
brew install guhttps/veu/veu
```

A fórmula é gerada pelo repositório principal ([guhttps/veu](https://github.com/guhttps/veu), `scripts/atualizar_manifestos.py`) a cada versão.
